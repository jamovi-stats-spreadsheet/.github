## What Is jamovi

jamovi is a Windows statistics program that looks like a spreadsheet. Researchers and teachers who already typed cases open jamovi stats spreadsheet, click an analysis, and read output beside the grid. jamovi analysis module extends that menu. jamovi R-based stats is the engine. jamovi data table is the `.omv` you keep.

JASP is the sibling with a stronger Bayesian-first reputation and APA blocks. PSPP is the SPSS-syntax sibling. jamovi’s identity is “the data never disappear behind a dialog.” Filters, computed variables, and modules stay on a sheet you entered.

Analyze tables you collected or teaching files the course may use. Keep the `.omv` with the codebook. Do not load identifiable student grades into a public example.

## Starting with jamovi

Prerequisites: A PC you administer and a case table you are allowed to analyze.

1. **Prepare:** Enter or import the sheet with labels from the codebook you already keep.
2. **Configure:** Set measure types in jamovi stats spreadsheet and save the `.omv` with the study name.
3. **Test:** Run descriptives and confirm N.
4. **Refine:** Add the confirmatory jamovi analysis module, and compute any variables the protocol defined.
5. **Apply:** Use jamovi R-based stats output in the report you write.
6. **Maintain:** Archive jamovi data table with the protocol, and strip identifiers before sharing teaching copies.
